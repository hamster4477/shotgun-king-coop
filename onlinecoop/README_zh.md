# 合作模式：本地与局域网

**简体中文 | [English](README.md)**

只启用这一个模组，即可游玩**王座、无尽、剿灭的本地合作与局域网合作**。六个入口直接加载同一份卡牌、战斗和战役源码。本地游玩不需要联机助手。联机时双方选择相同入口：**局域网合作、局域网无尽或局域网剿灭**；选错模式会在开局前提示。

局域网剿灭由房主管理战役存档、余烬、烙印商店及开始下一轮。2P 显示准备摘要（等级、余烬、已购烙印），可按铃提醒房主，购买仍由房主操作。结算后房主返回准备界面即可再开一轮，无需重新连接。无尽后期的增援揭示由房主点击继续；这类等待输入的界面不会一直占用完整动画锁。

旧 `coop` 请保持停用，可作为备份保留，但以后不再修改它。合并版保留 `onlinecoop` 文件夹名，现有 Steam 启动路径仍然有效。存档继续使用已有的 `onlinecoop` 存档；旧 `coop` 的解锁进度不会自动合并，也不会被删除。

修复黑骑士独立行动改变主教／城堡攻击线后，愚者盾仍使用旧危险格而漏报的问题，包括宗教裁判主教看穿隐身的情况。本地与联机共用此修复。

当前版本：**Unified 72 LAN 1**。房主（1P）控制黑王，加入者（2P）控制黑骑士。双方运行自己的游戏；战斗与规则由房主结算，2P 接收画面、状态并提交操作。

抽卡权重：通缉令、悬赏骑兵已恢复基础权重 4；革命、断头台也已恢复原版基础权重 4。入赘（现名裂颅）、骑士精神的基础权重为 5，其余 15 张新增合作卡为 4。

新增游戏提示跟随各自的游戏语言：简体中文显示中文，英文及其他语言使用英文后备。模组列表的固定介绍同时列出中英文。双方可以选择不同的显示语言。

## 1. 安装与启动

双方完全退出游戏，安装同一份 `coop-unified-r72c-lan-only.zip`，将包内 `onlinecoop` 文件夹放进游戏的 `mods` 文件夹。更新时完整覆盖模组文件，保留自己的存档。双方保持 Steam 开启。本版同时更新通信助手协议，不能只替换 Lua 文件而继续使用旧助手。

从 `mods/onlinecoop` 选择一个入口：

| 启动文件 | 用途 |
| --- | --- |
| `Start Online Co-op Multi Core.vbs` | 正常多核启动，不主动限制 CPU 核心；一般玩家使用此入口。 |
| `Start Online Co-op.vbs` | 单核兼容启动；需要单核绕过原生崩溃的电脑使用此入口。 |

两种 VBS 入口可以互相联机，无需双方选择相同 CPU 模式。单核是兼容性绕过办法，不保证修复所有崩溃。

启动后仍是原版主菜单。点击 **游玩 → 局域网合作／局域网无尽／局域网剿灭** 才打开大厅，也可以先玩王座等原版模式。后台通信助手隐藏运行，退出游戏后自动结束；玩家不需要安装 Python、LuaSocket 或额外 DLL。

本地安装的 VBS 入口会临时只启用 onlinecoop，退出后恢复原模组启用列表；如果游玩期间主动修改列表，则保留你的修改。它不修改 `mods/coop` 的文件。不要同时启用 coop 和 onlinecoop，它们含有同名卡牌与规则。

### Steam 创意工坊安装

[在 Steam 创意工坊订阅](https://steamcommunity.com/sharedfiles/filedetails/?id=3833493529)。下载完成后，在安装游戏的 Steam 库中打开以下文件夹：

```text
steamapps\workshop\content\1972440\3833493529\
```

在此目录双击 **Configure Steam Launch.vbs**，选择账号并“应用并重启 Steam”。默认多核，需要时勾选单核兼容。之后从 Steam 启动游戏即可进入局域网合作；也可以直接双击工坊目录中的两种 Online Co-op VBS 入口。订阅本身不会执行这些脚本，需要手动配置一次。

启动器会根据工坊数字目录识别项目 ID，通过 Steam 游戏安装清单定位游戏，并让通信助手使用这一份模组的 `lan` 目录；无需手动复制到游戏的 `mods`。启动期间只启用所选工坊项目，退出后恢复原启用列表（游戏中主动修改列表时保留修改），本地 `coop` / `onlinecoop` 文件不会被覆盖。缺失游戏安装、路径不正确或找到多个无法区分的安装时会提示错误。

工坊正常更新且项目路径不变时无需重新配置。移动 Steam 库、换工坊项目或取消订阅后，需重新配置或删除 Steam 启动选项。请退出游戏和联机助手后再更新模组；双方安装同一版本。

开发验证已覆盖模拟工坊路径、不同 Steam 库、数字启用 ID、原生游戏中的数字目录加载和通信、重复本地版本禁用及列表恢复。尚需发布后验证一次真实的“订阅 → 启动 → 工坊更新”流程。

上传者应选择干净的模组文件夹作为内容根目录（该目录直接包含 `info.lua` 和 `script.lua`），不要上传外层目录或 ZIP 本身，也不要上传开发目录里的旧压缩包、日志和测试记录。

## 2. 创建与加入房间

同一局域网可以点击大厅右上角 **附近房间**，等朋友创建房间后，点击列表中的电脑名称与地址即可加入。双方仍需选择同一种模式。房间列表自动刷新，已关闭的房间会在约六秒内消失。房间发现使用 UDP 27842；热点隔离、防火墙或不转发广播的组网工具可能使列表为空，此时可以用连接码加入。

大厅会显示所选网卡的名称，成功联机后记住房主使用的网卡，下次启动时优先选择仍可用的同一网卡。连接失败会显示更具体的原因，可点击 **重试**；房主重建房间后应获取新的连接码。输入框支持长按退格、Delete 连续删除，以及长按左右方向键移动光标。



1. 双方进入 **游玩**，选择相同的 **局域网合作／局域网无尽／局域网剿灭** 入口。
2. 房主点击 **创建房间 → 复制连接码**，将完整连接码发给朋友。
3. 朋友复制连接码，点击 输入框右侧的 **粘贴**，再点击上方的 **加入**，无需分别填写 IP、端口和密钥。
4. 连接并核对版本后，房主选择武器、难度并开始。2P 播放完自己的开场 CG 后等待房主；无需再次启动游戏。

地址自动读取。有多个网卡或组网工具时，房主在创建前点击地址切换，选择朋友能访问的地址。例如皎月连应使用房主的虚拟 IP，不能填加入者自己的 IP。端口默认 `27841`，被占用时尝试后续端口；实际端口已包含在连接码中。

连接码/端口输入框点击后会高亮并显示闪烁光标，支持左右键、Home/End、退格与 Delete。大厅的 **返回** 或 Esc 会取消本次连接/房间并回到菜单；未成功连接时可以取消后重试。

使用默认的局域网／组网方式时，两台电脑须在可互通的局域网，或先通过组网工具建立连接；SKCOOP1 连接码不会自动提供公网中继。Windows 若提示防火墙授权，请允许你所使用的可信网络。部分热点会隔离设备，即使连接同一热点也可能无法互访。

### 可选：内网穿透 / TCP 端口映射

点击游戏大厅底部“返回”旁边的 **穿透设置（可选）**，在独立设置页开启 **使用对外连接地址**。这项设置只改变发给朋友的连接地址；隧道仍须在第三方工具中配置并保持运行。朋友仍然只需先“粘贴”、再“加入”，不必开启此选项。

以 Sakura FRP（樱花内网穿透）为例，隧道客户端和游戏在同一台房主电脑上：

1. 开启映射选项，默认选择本地 `127.0.0.1`，端口 `27841`。本地监听端口可以改为 1024～65535。
2. 在 Sakura FRP 创建 **TCP** 隧道，本地 IP 和本地端口与游戏上方的“本地”和“端口”一致。
3. 启动隧道，复制它提供的 **对外域名:远程端口**。在穿透设置页的对外地址框旁点击“粘贴”；也支持 `tcp://域名:端口`。
4. 点击“创建房间”，等显示等待朋友加入后，点击“复制连接码”发给朋友。对外端口可以与本地端口不同，不要将远程端口填入本地端口框。

对外地址会在本机记住；每次打开游戏时映射开关默认关闭，使用时需开启。等待朋友加入期间可以修改对外地址并重新复制连接码。修改后请发新的连接码。映射模式不会自动更换被占用的本地端口：请修改本地端口，并同步修改隧道目标端口。

| 连接方式 | 游戏中的设置 |
| --- | --- |
| Sakura FRP、原生 frp、NATAPP 等普通 TCP 隧道 | 开启映射，填写隧道对外域名/IP 和远程端口。同机代理一般转发到 `127.0.0.1:本地端口`。 |
| 路由器 TCP 端口转发 + 公网 IPv4 / DDNS | 开启映射后，将“本地”切换到房主 LAN 地址；路由器转发到该地址和本地端口，对外框填公网 IP/DDNS 和外部端口。需有可入站的公网地址。 |
| ZeroTier、Tailscale、皎月连等虚拟局域网 | 通常无需开启映射。先连接组网工具，再启动游戏，选择朋友能访问的虚拟网卡 IPv4，直接创建并分享连接码。双方需具备网络访问权限。 |
| 隧道程序在另一台局域网设备上 | 将游戏“本地”切换到房主 LAN IPv4，让隧道转发到该地址和端口。 |

支持数字 IPv4、能解析到 IPv4 的域名（含 DDNS）以及 1～65535 的对外端口。不支持纯 IPv6、HTTP/HTTPS 网页隧道、UDP-only 隧道或要求应用识别 PROXY protocol 的转发。这里是通用 TCP 地址适配，不会自动登录服务商、创建隧道或修改路由器。平台的访问认证、虚拟网络授权和防火墙仍须按相应工具配置。

已验证本机 TCP 转发、域名连接、不同内外端口、双向数据和端口冲突；未逐一实测各服务商的公网链路。参考官方说明：[Sakura FRP](https://doc.natfrp.com/game/other-games.html)、[frp](https://gofrp.org/en/docs/features/tcp-udp/)、[NATAPP](https://natapp.cn/article/tcp)、[ZeroTier](https://docs.zerotier.com/start/)、[Tailscale](https://tailscale.com/docs/use-cases/personal-or-at-home-use/share-private-game-server)。

## 3. 可选：从 Steam 启动（单核入口已验证）

双击 **`Configure Steam Launch.vbs`**，脚本会自动识别 Windows、游戏和 Steam 路径。选择 Steam 账号，默认多核；需要限制单核时，勾选“单核兼容模式”。 账号列表显示 Steam 昵称与 ID，识别到当前登录账号时会标注并自动选中。最近登录会单独标注；无法确认当前账号时，请按昵称选择。

- **复制**：复制完整启动选项，手动粘贴到 Steam 游戏属性。
- **应用并重启 Steam**：正常退出 Steam，等退出完成后备份并写入所选账号的启动选项，然后重新打开 Steam。不需要手动退出或填写路径。请先结束正在玩的游戏，并处理 Steam 自身弹出的提示。

仅替换本游戏的启动选项，界面会显示原有内容。备份在该账号的 `config` 目录，文件名为 `localconfig.vdf.onlinecoop-时间-编号.bak`。若 Steam 在 45 秒内未退出，不会强制关闭或写入。多个账号时请确认选择正确；无法自动识别时可浏览选择 `steam.exe`，也可用复制功能。下方是手动配置方法。


2026-10-29，玩家已确认以下单核入口能从 Steam 成功启动游戏。在 Steam 中右键游戏 → **属性 → 通用 → 启动选项**，填写这一整行：

```text
"C:\Windows\System32\wscript.exe" "<游戏实际安装目录>\mods\onlinecoop\Start Online Co-op.vbs" %command%
```

将 `<游戏实际安装目录>` 整段替换为实际游戏文件夹的完整路径，去掉尖括号。例如：

```text
"C:\Windows\System32\wscript.exe" "D:\Program Files (x86)\Steam\steamapps\common\Shotgun King The Final Checkmate\mods\onlinecoop\Start Online Co-op.vbs" %command%
```

Steam 库不一定在 `Program Files (x86)`，请勿只改盘符。保留英文双引号和末尾的 `%command%`。需要多核时，仅将文件名改为 `Start Online Co-op Multi Core.vbs`；多核入口从 Steam 启动尚未单独实测。

第一个程序也必须写完整路径：`"C:\Windows\System32\wscript.exe"`。本次实测中仅写 `wscript.exe` 会让 Steam 报“游戏可执行文件缺失”（OS Error 2），即使游戏和 VBS 文件都存在。若 Windows 安装在其他目录，请使用该系统实际的 `System32\wscript.exe` 路径。

配置后点击 Steam 的 **开始游戏**，再选择 **局域网合作**。本次确认范围是成功启动游戏，不代表完成了两台电脑的联机全流程验证。若启动失败，删除这项新增启动配置，改为直接双击 VBS。已有其他启动选项时，先保留原文。未配置启动选项时，Steam 普通启动不会自动开启通信助手。

## 4. 对局操作

每层第一回合由黑王先行动。之后通常依次为黑骑士 → 黑王 → 白棋结算。等待动画结束和合法格提示出现后操作。

| 玩家/操作 | 功能 |
| --- | --- |
| 1P | 原版黑王移动、开枪、上弹、选卡及法杖等操作。 |
| 2P 左键合法格/目标 | 黑骑士移动或攻击；规则仍由房主结算。 |
| 2P Tab | 跳过黑骑士行动。 |
| 2P 右键 | 取消当前灵魂选择。 |
| 2P C / V | 卡牌超过一页 / 灵魂超过五槽时翻页。 |
| 任一玩家 E，随后点格子 | 单次标点，点完自动退出；再次按 E 或右键取消。也可点击左下叹号进入。 |
| 2P 点选卡上组/下组 | 向 1P 发送选卡建议；最终选择由 1P 确认。 |
| 2P 左键铃铛 | 提醒 1P，双方播放同一铃声并显示按铃动画，冷却 0.3 秒。 |

标点出现时闪一下，约 3 秒后消失；每人保留一个，新标点替换自己的旧标点，换层清除。改变选卡建议会给 1P 播放提示音，重复选择同一组不会重复播放。按铃有 5% 概率播放 3 号彩蛋，其余随机播放 1、2 号。

持有「入赘」时，2P 可选择主教/城堡灵魂并按对应走法移动；「骑士精神」使用骑士灵魂，再左键选同行/同列的格子锚定冲锋。右键取消选择不消耗灵魂。黑骑士死亡后，在黑王可行动时点击骑士灵魂复活，复活当回合黑骑士不能再行动。

持有「机关号令」时，2P 在骑士行动阶段点击左下六点图标，每层一次。骑士先牺牲，下回合生成六个幻影骑士；幻影骑士由 1P 按原版黑棋拿放方式控制。

2P 可查看已持有卡牌（包含重复卡）、灵魂、武器/弹药、刀锋及棋子状态。悬停其他棋子查看状态，悬停卡牌显示名称。显示「等待房主确认」时请等待；请求被拒绝后按刷新后的合法格重新操作。

## 5. 动画、网络与帧率

新开局默认 **完整动画模式**。任一玩家按 **F7** 切换，两端同步；当前动作和已收到的动画播完后生效，本局换层保留，重新进入模式恢复默认。CG 期间不切换。

| 模式 | 适用情况 |
| --- | --- |
| 追帧模式 | 动画期间使用短暂的自适应缓冲，限制在途画面数量，拥塞时自动降低发送频率；必要时跳过旧画面。进入可操作阶段立即显示最新收到的画面。 |
| 完整动画模式 | 缓存足够且网络能跟上时边接收边播放，保留采集到的帧和时间间隔；慢网络或反复断流时增加缓冲，完整播放后才解除棋盘操作锁。 |

**F6** 循环选择 `10 / 15 / 20 / 30 / 45 / 60` 帧采集上限，默认 `30`。它控制同步采集，不改变回合规则或游戏速度。追帧模式遇到拥塞会自动降到所选上限以下，网络恢复后逐渐提高；完整模式保留所选采集上限。帧率提示按键后显示约 3 秒，平时隐藏。网络差可先调低帧率，重视完整动作可试 F7。

棋盘使用无损帧间压缩，复用重复像素，不降低分辨率或改变颜色；静止画面和重复的 Boss 绘制数据不再反复发送。对方加载或暂时不能接收消息时，通信助手会限制发送量，避免撑满队列。以上优化可以减少传输量和到包抖动，但无法消除实际网络延迟、长时间断流或带宽不足。

完整动画使用有上限的小批量传输，减少本地文件和网络写入开销。操作消息会立即刷新前面的批次，不会等凑满再发。回放保留采集帧的顺序和时间间隔；慢网络下可能先缓冲，再连续播放，减少动作中途反复停顿。

完整模式会沿用前面动作的网络缓冲经验，换层后也保留；网络恢复稳定时逐渐缩短缓冲。客户端提前解码少量后续帧，减少临到显示时的解码工作。网络较差时起播可能稍晚，但不会为追赶进度跳过已收到的动画帧。

隐藏 Boss 变身、拾取书籍及结局离场在普通回合暂停时仍保持完整回放。这些剧情阶段采集整幅画布，包含侧边卡牌特效、顶部画面、台词及原生调色闪屏。完整模式会在第一张剧情帧前先收齐该片段，避免变身播到一半因网络断流而暂停；普通战斗仍只采集棋盘并边接收边播放。剧情选项会在前一段动画播完后允许操作。

完整模式不会补造未采集的帧，也不能消除本机渲染卡顿。单段动作的保护上限为 7,200 帧、24 MB 编码画面数据和两分钟；极端情况触顶时保留最终画面并记录截断，超出上限的内容不保证完整。剧情文字使用 2P 当前字库在本地高清重画；双方语言或字体不同时，字形及字库覆盖范围可能不同。部分后处理着色器效果及音效尚未进入像素回放通道。开场、关底过场与结尾 CG 在双方本地分别播放，不要求逐帧同步。

## 6. 排错与反馈


| 现象 | 检查/处理 |
| --- | --- |
| Steam 提示可执行文件缺失 | 先检查开头是否为带引号的系统 `wscript.exe` 完整路径，以及后面的 VBS 路径是否存在。 |
| 提示助手未启动 | 用任一 Online Co-op VBS 启动；Steam 入口参见第 3 节。 |
| 版本不同 | 双方退出后覆盖同一份完整发行包，再重建连接。 |
| 连接超时/被拒绝 | 核对房主地址、助手是否运行、组网连接和防火墙；热点可能隔离设备。 |
| 画面卡顿 | 先用 F6 降低采集帧率；F7 完整模式可换取更完整的动作，但会增加等待。 |
| 对局中断线 | 暂不支持断线重连，请双方完全退出再建立连接。 |

报错时保留游戏目录的 `log.txt`、最新 `crash_log_*.txt`，以及当前会话的 `mods/onlinecoop/lan/<会话>/error.txt`（若存在）和 `lan/lobby/<会话>/broker*.log`。说明双方角色、楼层、最后操作、F6/F7 设置。分享前删去连接码与房间密钥。

当前不支持中途加入、断线续局或交换角色。2P 复用原版棋盘画面并补充界面，尚不保证所有原版/第三方模组特效及详细提示完全相同。原生崩溃与网络断线不是同一种故障。
